# Portfólio profissional

Portfólio profissional desenvolvido por **Guilherme Souza** como atividade da disciplina **Design Profissional**.

O projeto apresenta minha formação, competências, áreas de interesse e projetos desenvolvidos durante minha trajetória acadêmica e profissional.

## Sobre o projeto

Este portfólio foi desenvolvido utilizando HTML5 e CSS3, com foco em uma apresentação profissional, responsiva e acessível.

O projeto utiliza uma interface com tema escuro, combinação de preto e amarelo e organização baseada em seções e cartões.

O site apresenta:

- Apresentação profissional
- Sobre mim
- Formação acadêmica
- Competências técnicas
- Competências comportamentais
- Projeto desenvolvido
- Currículo
- Links profissionais
- Informações de contato

## Objetivos

Os principais objetivos do projeto são:

- Desenvolver um portfólio profissional utilizando HTML5 e CSS3;
- Aplicar conceitos de estruturação semântica;
- Praticar estilização e organização visual com CSS3;
- Desenvolver um layout responsivo;
- Aplicar conceitos básicos de acessibilidade;
- Apresentar minha trajetória acadêmica e profissional;
- Publicar o projeto utilizando o GitHub Pages.

## Tecnologias utilizadas

As principais tecnologias e ferramentas utilizadas no desenvolvimento são:

- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages
